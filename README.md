# Praxyl

/præk sɪl/

An Experimental Lightweight TypeScript Runtime in Rust.

This project is derived from the [Kakera AVG Engine](https://github.com/dort0306/kakera-avg) and aims to explore a new generation of JavaScript runtime that can run TypeScript directly while balancing lightness and efficiency.
